# @lobstah/ledger

Append-only signed-receipt log + balance computation for the Lobstah grid.

Part of [Lobstah](https://github.com/marouenbg/lobstah) — distributed P2P LLM inference grid for Apple Mac mini. The lobstah way.

## Install

```sh
npm install @lobstah/ledger
```

## What it does

See the [main README](https://github.com/marouenbg/lobstah#readme) for the full architecture, plus [packages/ledger/](https://github.com/marouenbg/lobstah/tree/main/packages/ledger) for the source.
