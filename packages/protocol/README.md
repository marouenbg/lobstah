# @lobstah/protocol

Ed25519 + Schnorr identities, signed receipts and announcements (canonical JSON), Zod request schemas, replay-protection helpers, URL safety checks for the Lobstah distributed-inference grid.

Part of [Lobstah](https://github.com/marouenbg/lobstah) — distributed P2P LLM inference grid for Apple Mac mini. The lobstah way.

## Install

```sh
npm install @lobstah/protocol
```

## What it does

See the [main README](https://github.com/marouenbg/lobstah#readme) for the full architecture, plus [packages/protocol/](https://github.com/marouenbg/lobstah/tree/main/packages/protocol) for the source.
