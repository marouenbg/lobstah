# @lobstah/router

Local HTTP server openclaw and other OpenAI-compat clients point at: model-aware multi-peer routing with failover, receipt validation + nonce dedupe, append to local ledger.

Part of [Lobstah](https://github.com/marouenbg/lobstah) — distributed P2P LLM inference grid for Apple Mac mini. The lobstah way.

## Install

```sh
npm install @lobstah/router
```

## What it does

See the [main README](https://github.com/marouenbg/lobstah#readme) for the full architecture, plus [packages/router/](https://github.com/marouenbg/lobstah/tree/main/packages/router) for the source.
