# @lobstah/worker

Provider-side HTTP server for the Lobstah grid: signs receipts, OpenAI-compat (streaming + non-streaming), optional auto-publish via Nostr or HTTP tracker.

Part of [Lobstah](https://github.com/marouenbg/lobstah) — distributed P2P LLM inference grid for Apple Mac mini. The lobstah way.

## Install

```sh
npm install @lobstah/worker
```

## What it does

See the [main README](https://github.com/marouenbg/lobstah#readme) for the full architecture, plus [packages/worker/](https://github.com/marouenbg/lobstah/tree/main/packages/worker) for the source.
