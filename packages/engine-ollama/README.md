# @lobstah/engine-ollama

Ollama adapter and WorkerEngine interface for Lobstah workers (chat + streaming chat).

Part of [Lobstah](https://github.com/marouenbg/lobstah) — distributed P2P LLM inference grid for Apple Mac mini. The lobstah way.

## Install

```sh
npm install @lobstah/engine-ollama
```

## What it does

See the [main README](https://github.com/marouenbg/lobstah#readme) for the full architecture, plus [packages/engine-ollama/](https://github.com/marouenbg/lobstah/tree/main/packages/engine-ollama) for the source.
